# Carpeta de imágenes para el portafolio

Coloca aquí las siguientes imágenes para que se muestre correctamente el portafolio de Pablo Martínez:

## Imagen de Perfil
- **perfil.jpg** - Foto de perfil de Pablo (la foto con el hombre de camiseta azul)

## Imágenes de Proyectos
Coloca 3 imágenes de proyectos web design:
- **proyecto1.png** - Primera imagen de web design (puedes usar cualquiera de las imágenes de interfaces que adjuntaste)
- **proyecto2.png** - Segunda imagen de web design
- **proyecto3.png** - Tercera imagen de web design

## Ejemplo de estructura:
```
html/
├── images/
│   ├── perfil.jpg           (la foto de perfil)
│   ├── proyecto1.png        (diseño web 1)
│   ├── proyecto2.png        (diseño web 2)
│   ├── proyecto3.png        (diseño web 3)
│   └── README.md            (este archivo)
├── index.html
├── index2.html
├── indexnavbar.html
├── indexnavbar2.html
└── indexpm.html
```

## Tamaños recomendados:
- **perfil.jpg**: 400x500 px (relación 4:5)
- **proyectos.png**: 900x600 px (relación 3:2)

Una vez coloques las imágenes en esta carpeta, el portafolio en `indexpm.html` mostrará automáticamente todas las fotos.
